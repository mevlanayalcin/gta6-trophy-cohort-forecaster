Forecasts every GTA VI PS5 trophy's Exophase earn rate at the end of week one. The model combines a players-tracked refresh trajectory, trophy-archetype earner growth, a damped logit trend and refresh-aware uncertainty, then enforces story, completion and platinum monotonicity plus a physical earner floor.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```
